# AI Social Media Content Project

## 📌 Overview
This project is a responsive web page that showcases 3 social media posts created with the help of AI tools. It demonstrates how multiple AI systems can be combined into a structured workflow to produce high-quality content.

## 🚀 Technologies Used
- HTML5
- CSS3 (Flexbox & Grid for layout)
- ChatGPT (idea generation, planning, captions, hashtags)
- DALL·E (visual generation)

## 🎯 Project Goals
- Create 3 high-quality social media posts
- Use AI tools for planning and content creation
- Present the final result in a structured and visual format

## 📱 Content Structure
Each post includes:
- Platform (Instagram)
- Target Audience
- Caption (with hook & call to action)
- Visual (AI-generated or placeholder image)

## ⚙️ How to Run the Project
1. Download or copy the project file
2. Save it as `index.html`
3. Open it in any web browser

## 🧠 Workflow
1. Defined the idea (Frontend Developer personal brand)
2. Used ChatGPT for:
   - Audience definition
   - Post ideas
   - Caption writing
   - Hashtags
3. Generated prompts for AI images
4. Created visuals using DALL·E
5. Built the final layout using HTML & CSS
